# Workspace Customizations & Agent Rules

## Git Remote & Credentials
- The GitHub remote URL for this repository is configured with the user's GitHub Personal Access Token in local `.git/config`.
- When running `git push` or `git pull`, always use `origin` or the authenticated remote URL so non-interactive background commands succeed cleanly without hanging on credential popups.

## Commit & Push Policy
- **Push Everything Every Time**: Always commit and push all code, assets, and documentation changes to GitHub immediately after completing any feature, fix, or update.
- **Detailed Simple English Commit Messages**: Write super detailed commit messages that explain exactly what was changed, fixed, or built using simple, easy-to-understand English so anyone reading the GitHub history understands it clearly.
